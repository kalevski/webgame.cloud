### tc-screen-flash

Full-screen flash effect for damage hits and scene transitions. Styled to the toolcase design system: no shadow DOM — a flat fill `<div>` that JS animates from a peak opacity back to transparent. The host sits `position: fixed; inset: 0` with `pointer-events: none` so it covers the viewport without blocking interaction. A flash is triggered by changing the `trigger` attribute to a new non-null value, or by calling the imperative `flash()` method. A `tc-done` event fires when the fade-out completes.

**Tag:** `tc-screen-flash`

---

#### Attributes

| Attribute | Type | Default | Description |
|---|---|---|---|
| `flash-color` | CSS color | `#ffffff` | Fill color for the flash (any CSS color value, e.g. `#dc2626`, `var(--tc-app-accent)`). Written as an inline style override on the fill div. |
| `flash-opacity` | number (0–1) | `1` | Peak opacity reached at the start of the flash. Clamped to [0, 1]. |
| `duration` | number (ms) | `200` | Fade-out duration in milliseconds. Values ≤ 0 fall back to the default. |
| `trigger` | string | — | Set to any new non-null string to trigger a flash. Changing to the same value again is a no-op; only distinct values re-trigger. |

---

#### JS Properties

| Property | Type | Description |
|---|---|---|
| `flashColor` | `string` | Reflects `flash-color` (default `#ffffff`) |
| `flashOpacity` | `number` | Reflects `flash-opacity` (default `1`, clamped 0–1) |
| `duration` | `number` | Reflects `duration` in ms (default `200`) |
| `trigger` | `string \| null` | Reflects `trigger`; setting a new non-null string fires a flash |
| `onDone` | `(() => void) \| null` | Optional callback fired alongside `tc-done` |

#### Imperative API

| Method | Description |
|---|---|
| `flash()` | Triggers a flash immediately without touching the `trigger` attribute |

---

#### Events

| Event | Detail | Description |
|---|---|---|
| `tc-done` | `{}` | Fires when the fade-out transition completes (or immediately when `prefers-reduced-motion` is active) |

---

#### CSS custom properties

| Property | Default | Description |
|---|---|---|
| `--bs-screen-flash-color` | `#ffffff` | Default fill color (overridden inline by the `flash-color` attribute) |
| `--bs-screen-flash-z` | `var(--tc-z-tooltip, 1070)` | Stacking order — sits above all UI layers |

---

#### Slots

None. All content is generated by the component.

---

#### Example

```html
<!-- Trigger a red damage flash on a keypress -->
<tc-screen-flash
  id="dmg"
  flash-color="#dc2626"
  flash-opacity="0.55"
  duration="250"
></tc-screen-flash>
<script>
  const flash = document.querySelector('#dmg')
  let _seq = 0

  flash.addEventListener('tc-done', () => {
    console.log('flash complete')
  })

  // Attribute-driven: set trigger to a new value each time
  document.addEventListener('keydown', e => {
    if (e.key === 'h') flash.trigger = String(++_seq)
  })

  // Or use the imperative API
  document.addEventListener('keydown', e => {
    if (e.key === 'j') flash.flash()
  })
</script>
```
